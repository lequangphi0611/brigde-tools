# Feature specs

Mỗi user story một thư mục `NNN-slug/` (ví dụ `003-add-project-by-url/`), sinh bởi workflow `/feature`:

- `spec.md` — theo `_template.md`. Là **nguồn sự thật** cho e2e và implement.

Không lưu prompt gửi Claude Design ở đây; chỉ lưu kết quả design đã chốt (mô tả UI, state, copy) vào mục "UI" của spec.
